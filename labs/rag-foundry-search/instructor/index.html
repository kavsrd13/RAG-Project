Build a RAG Agent with Azure AI Foundry and Azure AI Search

In this exercise, you build a Retrieval Augmented Generation (RAG) assistant by combining Azure OpenAI models from Azure AI Foundry with Azure AI Search.

Tasks performed in this exercise:

  • Create Azure AI Foundry, Azure AI Search, and a resource group.
  • Deploy a chat model and embedding model.
  • Configure credentials in an environment file.
  • Create a Python virtual environment and install dependencies.
  • Run ingestion to index PDF chunks and embeddings.
  • Run the RAG agent and validate grounded responses.
Estimated time: 50 minutes.

Before you start

To complete this lab, you need:

  • An Azure subscription with permissions to create resources.
  • Visual Studio Code.
  • Azure CLI installed and signed in.
  • Python 3.10 or later.

Sign in to Azure

az login
az account show --output table

Create Azure resources

Create a resource group, Azure AI Foundry resource, and Azure AI Search service.

Set working variables (PowerShell)

$RG = "rg-rag-lab"
$LOC = "eastus"
$FOUND = "foundry-rag-lab-001"
$SEARCH = "srchraglab001"
$PROJECT = "rag-project"

az group create --name $RG --location $LOC

Create Azure AI Foundry resource

az cognitiveservices account create `
  --name $FOUND `
  --resource-group $RG `
  --location $LOC `
  --kind AIServices `
  --sku S0 `
  --yes

Create Azure AI Search

az search service create `
  --name $SEARCH `
  --resource-group $RG `
  --location $LOC `
  --sku basic
AI Foundry projects can also be created in the Azure AI Foundry portal. If your tenant requires portal onboarding, create the project there and use its endpoint in the next sections.

Capture credentials

Collect these values from portal/CLI:

  • Foundry project endpoint.
  • Azure OpenAI key (or use Entra identity).
  • Search endpoint and admin key.
  • Search index name (example: benefits).

Get Search keys from CLI

az search admin-key show --service-name $SEARCH --resource-group $RG --output table

Local environment setup

Create Python virtual environment

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt

Configure .env

AZURE_FOUNDRY_ENDPOINT=https://<your-foundry-resource>.services.ai.azure.com/api/projects/rag-project
AZURE_OPENAI_DEPLOYMENT=gpt-4o
AZURE_OPENAI_EMBEDDING_DEPLOYMENT=text-embedding-3-small
AZURE_SEARCH_ENDPOINT=https://<your-search-service>.search.windows.net
AZURE_SEARCH_INDEX=benefits
AZURE_OPENAI_API_KEY=<openai-key>
AZURE_SEARCH_API_KEY=<search-admin-key>
Never commit real secret values to git. Keep .env local.

Run and test

Ingest documents

python ingest.py

Run chat assistant

python main.py

Sample test prompts

  • What is covered in Northwind Standard Benefits?
  • Which document describes employee perks?
Expected behavior: terminal prints retrieved chunks, then a final answer that references source documents.

Troubleshooting

  • If authentication fails, check AZURE_OPENAI_API_KEY and AZURE_SEARCH_API_KEY values.
  • If index not found, run ingest.py again and confirm AZURE_SEARCH_INDEX matches the created index.
  • If model errors occur, verify deployment names exactly match .env values.

Clean up

az group delete --name $RG --yes --no-wait
