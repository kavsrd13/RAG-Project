Lab Task: Build a RAG Agent End-to-End

Complete this exercise by provisioning Azure services, deploying models, filling environment values, and finishing key parts of the RAG pipeline code.

Estimated time: 50 minutes.

Before you start

  • Azure subscription with resource creation rights.
  • Visual Studio Code and Python 3.10+.
  • Azure CLI authenticated with your lab subscription.
az login
az account show --output table

Create Azure resources

Complete the values and run the commands.

$RG = "<your-resource-group>"
$LOC = "<your-region>"
$FOUND = "<unique-foundry-name>"
$SEARCH = "<unique-search-name>"

az group create --name $RG --location $LOC

az cognitiveservices account create `
  --name $FOUND `
  --resource-group $RG `
  --location $LOC `
  --kind AIServices `
  --sku S0 `
  --yes

az search service create `
  --name $SEARCH `
  --resource-group $RG `
  --location $LOC `
  --sku basic
